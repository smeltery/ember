FAQ

Questions, answered.

What does ember do?

ember is a macOS menu bar app that keeps your Mac awake while AI coding agents such as Claude Code, Codex, Cursor, and Gemini CLI are working, even with the lid closed. It holds a macOS power assertion only while an agent is mid-task and lets the Mac sleep again as soon as the agents go idle.

How is ember different from Caffeine or Amphetamine?

Caffeine and Amphetamine are manual or process-based toggles: they keep the Mac awake while you leave them on or while a process exists. ember reads the lifecycle hooks that Claude Code, Codex, and OpenCode expose, so it knows whether an agent is actually working versus sitting idle, and it releases the wake lock automatically when the work finishes.

Does it really keep a MacBook awake with the lid closed and no external display?

Yes. ember holds the PreventUserIdleSystemSleep assertion, the system-level assertion macOS honours for lid-closed operation, so it works without an external display or Apple’s closed-display mode. It runs on macOS 14 or later on both Apple Silicon and Intel Macs.

Which coding agents are supported?

Claude Code, Codex, and OpenCode are integrated through lifecycle hooks that report a real Working or Idle state per terminal session. Cursor, Gemini CLI, Aider, and Windsurf are supported through process detection.

Will it drain my battery?

ember ships with battery guardrails: a configurable battery cut-off threshold, an "only when plugged in" mode, respect for macOS Low Power Mode, and an option to turn the display off while agents run.

How much does ember cost?

ember is free and open source under PolyForm Shield 1.0.0. Download from GitHub Releases — no subscription.

Does ember send my code anywhere?

No. ember never reads your code, prompts, or terminal output. It only receives the Working and Idle hook signals from your agents and calls macOS power management APIs locally.
